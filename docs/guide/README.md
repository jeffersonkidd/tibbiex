# The Tibbie X Guide

How to run everything that was built for you: the site, the Studio and the
links that point at them. While you learn each tool, you also pick up a posting
habit, because using the tool well *is* the social media strategy. Every lesson
teaches both.

**Who it's for:** Tibbie, and anyone Tibbie trusts to post for the project. No
code, no terminal: everything here happens on a phone or in a browser.

**Where it lives:** these files for now. Later they become a **Guide** module
in the Studio (`/studio#guide`), next to Link Maker and Avatar, so the lesson
sits in the same place as the tool it teaches.

## How a lesson is written

Every lesson has the same five parts, so you always know where to look:

1. **Why** — one or two sentences: what this gets you.
2. **Do it** — the steps, in the words on the screen, with the button names in
   **bold**.
3. **Check it worked** — what you should see when it's right.
4. **If something's off** — the mistakes people actually make, and the fix.
5. **The habit** — what this tool means for how you post.

Rules for whoever writes the next one:

- Write for a phone in one hand. Short steps, one action each.
- Use the names the screen uses. If the Studio says **Make it live**, the
  lesson says **Make it live**.
- Only describe what the Studio does today. A module that isn't built yet gets
  a row in the table above, not a lesson.
- When a module changes, its lesson changes in the same commit.
